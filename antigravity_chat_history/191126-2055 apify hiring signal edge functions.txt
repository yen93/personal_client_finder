3. US OUTBOUND SALES HIRING-SIGNAL PIPELINE (ASYNC WEBHOOKS)
--------------------------------------------------------------------------------
* Problem / Context:
  Created a separate table and Edge Function targeting America-only SMBs hiring
  specifically for outbound sales / lead-generation roles (SDR, BDR, Lead
  Generation Specialist, Outbound Sales Representative). Initial large US
  synchronous batches hit Supabase's 150-second HTTP gateway timeout (504)
  because nationwide US LinkedIn results are enterprise-heavy.

* Technical Changes:
  - Created migration:
    supabase/migrations/20261119_create_us_sales_hiring_leads.sql
  - Created Edge Function:
    supabase/functions/us-sales-hiring-leads/index.ts (deployed as v1 -> v3)
  - Database schema (`public.us_sales_hiring_leads`):
    * Columns: `id` (uuid PK), `company`, `poc_name`, `poc_role`,
      `company_domain`, `hiring_role`, `job_location`, `job_url`, `source`,
      `created_at`, `updated_at`.
    * Constraint: `us_sales_hiring_leads_company_poc_unique UNIQUE (company, poc_name)`.
    * Trigger: `trg_us_sales_hiring_leads_updated_at` (`BEFORE UPDATE`).
    * Security: RLS enabled (`service_role` only).
  - Filtering & Enrichment Enhancements:
    * US-only location enforcement (`usLocation` auto-appends `, United States`;
      rejects non-US job locations).
    * Strict `isOutboundOrLeadGenJobTitle()` filter keeping outbound/SDR/BDR/
      lead-gen/appointment-setter/inside-sales roles and excluding retail,
      door-to-door, dealership, canvasser, and customer-service listings.
    * Strict `isNonTargetOrganization()` blocking universities (substring match),
      colleges, schools, hospitals, government, and 19 major US staffing mills
      (Robert Half, Randstad, TEKsystems, Insight Global, Jobot, etc.).
    * Default `includeUnknownSize: false` and `Math.max(companySize,
      companyEmployeeCount)` eliminated enterprise leakage (e.g., Cisco).
    * Sales/exec decision-maker scoring (`scoreSalesDecisionMaker`) prioritizing
      Founder/Owner/CEO/President -> CRO/VP Sales/Head of Sales -> COO/GM.
  - Async Apify Webhook Upgrade (v3):
    * Default `mode: "async"` launches `bebity` job runs via `POST /runs` with
      Base64-encoded ad-hoc webhooks pointing back to `?stage=jobs_done`
      (authenticated via `headersTemplate` with `SUPABASE_ANON_KEY`) and returns
      HTTP 202 in ~2 seconds.
    * `?stage=jobs_done` downloads the jobs dataset, filters SMBs, and launches
      async `deepmine` runs with a second webhook pointing to `?stage=pocs_done`
      carrying only `jobsDatasetId` + `config`.
    * `?stage=pocs_done` fetches both datasets, matches top 1 POC per company,
      and upserts into `public.us_sales_hiring_leads` with zero staging tables
      and zero 150s timeouts.
